# MODRACX Brand Guidelines

## Voice

- Direct, technical, and practical.
- Focus on outcomes, systems, and clarity.
- Avoid hype. Emphasize what the work does.

## Visual Direction

- Theme name: Digital Workshop
- Mood: command-center, workshop, OS dashboard, terminal
- Style: high-contrast, glassy surfaces, structured grids, purposeful motion

## Color System

- Background: `#050607`
- Surface: `#0B1219`
- Elevated: `#111A24`
- Primary accent: `#D6A45B`
- Secondary accent: `#49D6C4`
- Warm accent: `#F28B62`
- Text primary: `#F7F3EA`
- Text secondary: `#C2CCDA`

## Typography

- Display: `Space Grotesk`
- Body/UI: `Inter`
- Mono: `JetBrains Mono`

## Principles

- Use rooms, dashboards, and terminals to explain capability.
- Prefer systems thinking over generic portfolio storytelling.
- Keep interactions accessible, readable, and fast.
