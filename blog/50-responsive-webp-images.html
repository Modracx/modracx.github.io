Optimizing Image Delivery with Responsive Images

Automating WebP/AVIF generation in Magento 2 using Sharp or Cloudinary transforms raw product uploads into optimized viewport-sized variants on the fly.

By Kenneth D'Silva • Reading Time: 34 min read • Category: Performance & Speed

Sharp Node.js Image Conversion Script

// Sharp Node.js Dynamic WebP / AVIF Generation Script
const sharp = require('sharp');

sharp('product.jpg')
  .resize(800)
  .toFormat('avif', { quality: 80 })
  .toFile('product-800.avif');
